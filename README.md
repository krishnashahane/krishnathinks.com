# krishnathinks.com

Source code of my personal website, [krishnathinks.com](https://krishnathinks.com): my work across AI engineering, security, full-stack development, developer tools and research.

## Structure

- `index.html`: home page
- `ai-engineer/`, `security-engineer/`, `full-stack-developer/`, `tools-builder/`, `researcher/`: project rooms
- `ability-card/`: interactive 3D ability card
- `legal/`: legal notice and third-party licences
- `vendor/`, `fonts/`: self-hosted libraries and typefaces
